### 🌟 Подробнее о главном проекте (Диплом)

**Образовательная интерактивная среда «Виртуальная Беларусь» (Unity, C#)**  
Разработана как дипломный проект в ГГАЭК. Представляет собой 3D-игру от первого лица с элементами виртуального туризма и экологического квеста. 

> 🎮 **Попробовать WebGL-версию можно на [Itch.io](https://astroleaf-studio.itch.io/virtual-belarus)** *(Внимание: это браузерная сборка, возможны незначительные просадки FPS по сравнению с нативной версией для Windows).*

*   **Геймплей и механики:** Реализован контроллер персонажа от первого лица (бег, прыжки, приседания, физическое взаимодействие с предметами). Разработана уникальная механика *реверса времени* (перемотка координат игрока назад с помощью кольцевого буфера). Система квестов, динамическая смена времени суток, интеграция мини-викторин для проверки знаний.
*   **Графика и оптимизация:** Создана Low-poly графика в Blender. Проведена серьезная оптимизация под слабые ПК: настроены уровни детализации (LOD Group), внедрено отсечение невидимых объектов (Occlusion Culling), написан кастомный шейдер с использованием массивов текстур (`Texture2DArray`) для объединения Draw Calls. Стабильные 150+ FPS даже в нагруженных сценах.
*   **Архитектура:** Проектирование структур данных (PlayerData, QuestData, LocationData и др.), написание чистой архитектуры на C# с использованием паттернов (Singleton, Event-driven), создание собственного редактора в Unity для сборки массивов текстур (Editor Window).
*   **Документация:** Написано руководство пользователя и программиста, проведено комплексное тестирование (Usability, стресс-тесты).
